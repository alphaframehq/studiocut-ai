StudioCut AI

A local-first video editor with an AI Director. Your media stays on your machine — originals are never copied or uploaded. Describe the edit in plain language, review the proposal, and approve it before anything touches your timeline.

Development status: Version 0.1.0 is unreleased. No installers have been published yet, and the app has not yet run on a real desktop. This page describes what is being built — not what you can download today.

Features

Everything below reflects the current state of the project in the repository. Where a capability is approximate or heuristic, that is stated plainly.

Edit

  • Versioned .studiocut project files with atomic save and reopen, and 50-step session undo.
  • Multi-track video, audio and caption timeline: move, trim, split, ripple delete, mute, solo, lock, linked audio/video clips, zoom, and 0.25–4× speed.
  • Real video preview driven by an audio-master clock.
  • Media import with FFprobe metadata, a SQLite index, thumbnails and waveforms. Originals are referenced by path and fingerprint — never copied.

Understand

  • Silence detection and local Whisper transcription, or cloud transcription with your own API key.
  • Kinetic captions in four presets.
  • Speaker turns, beat detection and reframing are heuristics, not machine learning: speaker turns are pause-based hints, beats are energy-based onset detection, and reframing is a centre crop — no face is detected or tracked.
  • Scopes (waveform, vectorscope, histogram) are approximate — computed from a sample frame no wider than 320 px. Use them as a grading aid, not a broadcast measurement.

Direct

  • AI Director and Chat-to-Edit: describe the edit in plain language and the Director proposes a single edit decision list, which you review and approve before anything touches the timeline. One undo checkpoint per approval.
  • The AI Director works with your own API keys (bring your own key). There is no built-in key and no cloud account.
  • MCP support is bring-your-own-key: connect your own MCP servers with your own credentials. Keys are stored in the operating system credential manager or session-only memory, never in project files.

Finish

  • Colour grading, LUTs (.cube), and audio mastering with ducking.
  • Deterministic FFmpeg export (MP4/MOV, 1080p/4K, 24/30/60 fps) with progress, cancel, validation and atomic publish. Existing files are never overwritten.
  • Finishing controls are export-only: the preview does not show grading yet.

Privacy & licensing

  • Local-first by design: media and projects stay on your machine.
  • An offline licence gates only AI Director proposals and export. Editing, import and transcription work unlicensed.
  • Known limits: no native desktop verification yet on real Windows, macOS or Linux hardware; no autosave yet — save explicitly; one export job at a time; a maximum of 128 clips per render.
