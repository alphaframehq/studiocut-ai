# StudioCut AI

- React 19, strict TypeScript, Vite, Tailwind, Zustand and Tauri v2 Rust backend; SQLite indexes media metadata, never API keys.
- Project formats v1–v6, 1 MB limit. v3 timelines, v4 captions, v5 effects, v6 optional finishing settings within effects. Atomic project save/reopen share Rust integration-tested functions.
- Timelines: integer frames, 32 tracks/2,000 clips/6 hours, no same-track overlaps. Linked A/V pairs share timing and speed. 50 undo snapshots per session. Speed-aware trims/splits/ripple require whole source-frame boundaries. Analyze/transcribe at original speed.
- Media: bounded FFprobe/FFmpeg, SQLite index at app_local_data_dir/media/media.sqlite3, UUID thumbnail/waveform cache. Originals never written. Native import 100 files/batch; browser reattachment/decode 64 MB.
- Preview: Web Audio master clock and corrected muted video, first eligible video only; existing zoom/LUT/gain effects previewed. New v6 finishing is export-only and labelled accordingly. Native WebView codec/performance verification remains open.
- Analysis: 50 ms stereo RMS; -38 dBFS/400 ms minimum/80 ms padding. Atomic reviewed ripple edits. Caption presets hormozi/minimal/documentary/neon with source-frame timings.
- Transcription: whisper-cli/model, 16 kHz mono WAV, 10 min/20 MB selection, 4 MB response. Groq/OpenAI/compatible multipart and OpenRouter audio JSON via Rust with consent; no invented word timing.
- Credentials: keyring v3 OS backends, explicit Zeroizing session fallback. Keys never enter project/Zustand/SQLite; endpoint scoped. Custom compatible endpoints require saved credentials. OS failures never silently fall back.
- Director: Gemini/OpenAI/Claude/Groq/OpenRouter/compatible, loopback Ollama, Bedrock bearer keys, Vertex OAuth. Bounded path-free context, explicit models, no provider fallback; 90 s timeout, one 429 retry, 8,192 output tokens/256 KB. Versioned prompt and strict EDL v1; TypeScript feedback plus Rust approval validation, one undo checkpoint. Browser only supports local proposal review/application.
- `finishing.rs` / `src/finishing.ts`: typed speed/color/transforms/audio settings; .cube import <=256 KB, size 2–33, RGB domain/value range 0..1. Embedded LUT data persists in project. Original identity/warm/cool 17³ presets generated deterministically, CC0 data license in src-tauri/luts/LICENSE.txt.
- `filtergraph.rs`: deterministic FFmpeg argument/graph/ASS/resource compilation; first video track topmost, mute/solo per track kind, gaps, trims, speed, transforms/opacity, LUT/eq/colorbalance, captions, afftdn/acompressor, voice-driven sidechaincompress and output limiter. Up to 128 active media clips per render to bound decoders.
- `render.rs`: one export worker; Tauri start/status/cancel. Protocol v1 latest-state snapshots with UUID/sequence/timestamp; polling reconnect recovers current state, no event-log replay or restart persistence. Bounded pipe diagnostics. Real encoder probes for NVENC/VideoToolbox/AMF/QSV and disclosed libx264 fallback.
- Export: MP4/MOV, 1080p/4K landscape, 24/30/60 fps, letterboxed canvas, AAC stereo 48 kHz. Snapshot/fingerprint checks; same-parent temp directory, real child kill/wait cancellation, FFprobe validation, file sync and non-overwriting atomic hard-link publication. Filesystems without hard links fail safely. Closing modal leaves job running; app restart recovery is not implemented.
- UI: Export modal accepts absolute output paths; Color/Audio inspector commits undoable edits. Browser explicitly reports native rendering unavailable.
- Checks: npm run build; cargo test/check/build --locked --manifest-path src-tauri/Cargo.toml; cargo fmt --manifest-path src-tauri/Cargo.toml -- --check. Tests require Node 24/FFmpeg/libass/libx264.
- Export integration tests cover real 1080p MP4/30, 4K MOV/24, 1080p MP4/60 with FFprobe, CPU fallback, two readers/reconnect, cancellation cleanup, non-overwrite, deterministic graph, LUT validation, persistence/history and mute/solo. Existing cross-language EDL tests load finishing.ts too.
- Browser fixture src-tauri/tests/preview.html uses retained real H.264/AAC; not a production entry. Export modal checked at 390/1280px; mobile audio and desktop grading undo/redo checked.
- Still open: actual desktop WebView export IPC/UI, hardware acceleration on supported machines, Windows/macOS qualification, live AI/transcription/model quality, OS-keychain round trips, packaged FFmpeg/models, installers/licensing.
